# Data model

The agreed data model. A design that changes the data updates this file in
its design stage, naming its work item, so the owner approves the model
before it's built. Migrations and ORM models implement it and stay the source
of truth for exact types. If the build must differ from what was agreed,
update this file and the design, and log a `scope` entry when it changes
what was approved.
